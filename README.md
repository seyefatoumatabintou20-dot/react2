Ouvre un terminal et tape npm create vite@latest 001 -- --template react pour créer le projet.

Tape cd 001 pour entrer dans le dossier.

Tape npm install pour télécharger les outils.

Tape npm run dev pour lancer le projet, puis ouvre l’adresse affichée dans ton navigateur.

Écris ton code dans le dossier src, surtout dans App.jsx.
